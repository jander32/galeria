# Freedom Tracker

Aplicación de consola para apoyar a las personas que desean dejar el tabaco, el alcohol o ambos.

## Características
- Registro diario de cigarrillos y bebidas evitadas.
- Cálculo de días sin consumir y dinero ahorrado.
- Medallas y mensajes motivadores.
- Diario de motivación.
- Rincón de emergencias con ejercicio de respiración y mensajes positivos.

## Requisitos
- Python 3.8 o superior.

## Uso
```
python main.py
```

Ejecutar una demostración rápida (sin interacción):
```
python main.py --demo
```
